2. Allgemeine Hinweise

Der Schutz deiner persönlichen Daten ist uns wichtig. Personenbezogene Daten werden auf dieser Webseite nur im erforderlichen Umfang verarbeitet.

3. Registrierung einer Kleiderspende

Im Rahmen der Registrierung einer Kleiderspende können unter anderem die Übergabeart, die Art der Kleidung und das ausgewählte Krisengebiet erfasst werden.

Bei einer Abholung werden zusätzlich Angaben zur Abholadresse, insbesondere Straße, Postleitzahl und Ort, sowie eine E-Mail-Adresse erfasst.

4. Speicherung der Daten

In dieser beispielhaften Webanwendung werden die Registrierungsdaten ausschließlich zur Darstellung der Bestätigungsseite innerhalb der aktuellen Browsersitzung verwendet.

Eine dauerhafte Speicherung auf einem Server oder in einer Datenbank findet in dieser Fallstudie nicht statt.

5. Zweck der Datenverarbeitung

Die erhobenen Angaben dienen dazu, eine Kleiderspende zu registrieren und die ausgewählte Übergabeart sowie das gewünschte Krisengebiet zu dokumentieren.

6. Weitergabe an Dritte

Eine Weitergabe der eingegebenen Daten an Dritte erfolgt innerhalb dieser beispielhaften Webanwendung nicht.

7. Technische Speicherung im Browser

Die Registrierungsdaten werden für die Bestätigungsseite vorübergehend im Browser gespeichert. Hierfür wird die JavaScript-Funktion „sessionStorage“ verwendet.

Die Daten stehen damit nur während der aktuellen Browsersitzung zur Verfügung und werden nicht über einen Server dauerhaft gespeichert.

8. Deine Rechte

Betroffene Personen haben grundsätzlich das Recht, Auskunft über die Verarbeitung ihrer personenbezogenen Daten zu erhalten. Darüber hinaus können je nach Voraussetzungen weitere Rechte, beispielsweise auf Berichtigung, Löschung oder Einschränkung der Verarbeitung bestehen.

9. Hinweis zur Hochschulaufgabe

Diese Webseite wurde im Rahmen einer Hochschulaufgabe als beispielhafte Webanwendung entwickelt. Die in dieser Datenschutzerklärung verwendeten Vereins-, Kontakt- und sonstigen Angaben sind Platzhalter.
